Customer-facing New York signs and graphics website at /nyc/, using your existing Contact Form 7 inquiry form.

== Description ==

Renders the Vision Graphics New York site under /nyc/: home, about, contact, product and service pages, service areas, sitemap and schema. Inquiries go to the Contact Form 7 form set in Settings → Vision Graphics NYC (MicroSiteForm_nyc).

Updates are delivered from GitHub Releases and appear as "Update now" on the Plugins screen.
